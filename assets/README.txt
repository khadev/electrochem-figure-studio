Component Library assets
========================
assets/components/   individual items (Nickel Foam, PPY, nanorods, arrows ...)  -> drag onto the canvas
assets/backgrounds/  full base images / 3D renders                            -> double-click to use as background

Drop your own PNG / JPG files here (sub-folders are fine). Use PNG with a transparent
background for components. The "Component Library" dock updates automatically
(or press Refresh).  File names become labels: "nickel_foam.png" -> "nickel foam".
The bundled samples were generated by tools/generate_sample_assets.py - delete or replace them freely.
